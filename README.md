# 📊 Employee Review Analytics | MINI PROJECT

## 📌 Project Overview

The Employee Review Analytics Dashboard is an interactive Power BI solution designed to analyze employee feedback, satisfaction levels, overall ratings, and regional performance trends. The dashboard transforms raw review data into actionable insights through meaningful visualizations and key performance indicators (KPIs).

This project demonstrates data cleaning, data modeling, DAX measure creation, and dashboard design using Power BI.

---

## 🎯 Project Objectives

- Monitor employee review trends over time.
- Analyze satisfaction and overall rating performance.
- Compare actual metrics with organizational targets.
- Evaluate ratings across job types and career growth levels.
- Identify regional differences in employee ratings.
- Support data-driven decision-making through visual analytics.

---

## 🛠️ Tools Used

- Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel

---

# 📈 Dashboard Structure

## 1️⃣ Executive Dashboard

This page provides a high-level overview of employee review performance through KPIs and trend analysis.

### KPI Cards
- Average Overall Rating
- Average Satisfaction
- Rating Variance
- Total Reviews

### Visualizations

#### Review Trend
- Visualization: Line Chart
- Purpose: Tracks review activity over time and highlights trends.

#### Average Overall Rating by Job Type
- Visualization: Pie Chart
- Purpose: Displays rating distribution across different job types.

#### Average Satisfaction by Job Type
- Visualization: Horizontal Bar Chart
- Purpose: Compares employee satisfaction levels among job categories.

#### Yearly Total Reviews vs Target Reviews
- Purpose: Evaluates actual review counts against target benchmarks.

#### Yearly Average Rating vs Target Rating
- Purpose: Measures performance against predefined rating targets.

---

## 2️⃣ Rating Analysis Dashboard

This page focuses on detailed rating and satisfaction analysis.

### Visualizations

#### Average Overall Rating by Career Growth
- Visualization: Bar Chart
- Purpose: Analyzes how career growth opportunities influence employee ratings.

#### Total Reviews by Satisfaction Category
- Visualization: Pie Chart
- Purpose: Shows the distribution of reviews across satisfaction groups.

#### Sum of Overall Rating by Year
- Visualization: Column Chart
- Purpose: Examines yearly rating patterns and performance trends.

---

## 3️⃣ Regional Analysis Dashboard

This page provides location-based insights.

### Visualizations

#### Rating Variance by City
- Purpose: Identifies differences in employee ratings across cities and regions.
